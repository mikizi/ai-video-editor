# Your Brand — Brand Defaults

These defaults apply to every OpenMontage production in this workspace unless
the user explicitly opts out for a specific project.

## Mandatory opening

- Start the deliverable with the full Your Brand opener video.
- The opener plays before program content and is never replaced by an
  autogenerated logo animation, title card, or still image.
- Canonical workspace source:
  `brand_assets/brand-opener.mp4`.
- Canonical project copy:
  `projects/<project-id>/assets/video/brand-opener.mp4`.
- Preserve the opener's native picture, motion, aspect ratio, frame cadence,
  and audio unless the user explicitly requests a modified version.
- Do not place editorial titles, source labels, music, or effects over the
  opener.
- Start the program soundtrack after the opener ends unless the opener itself
  contains a designed transition that calls for overlap.
- Treat the opener as branded pre-roll outside the requested program-content
  duration. For example, a 30-second recap remains 30 seconds of editorial
  content, and the delivered file runs for the opener duration plus 30 seconds.

## Override policy

Only omit or replace the opener when the user explicitly says so. Record the
override in the project's append-only decision log.

## Asset status

This repo ships **without** a brand opener. To enable one, drop your own
video at `brand_assets/brand-opener.mp4` and update `brand_assets/manifest.json`
(duration, codec, sha256). Until then the opener is skipped.

`lib.checkpoint.init_project()` copies it into every new project's
`assets/video/` directory and records its ready status in `project.json`.
Existing projects can be refreshed with
`lib.brand_assets.sync_existing_project()`.
